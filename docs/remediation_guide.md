# راهنمای رفع مشکلات امنیتی

اگر `security_audit.sh` مورد مشکوکی پیدا کرد، این راهنما کمک می‌کند قدم‌به‌قدم بررسی و برطرفش کنید.

⚠️ **قبل از هر اقدامی**: هیچ فایل یا پردازشی را که مطمئن نیستید چیست حذف نکنید. در صورت شک، هش فایل یا نام پردازش را جستجو کنید یا از یک متخصص کمک بگیرید.

---

## ۱. چگونه یک پردازش مشکوک را ببندیم (kill)

```bash
ps -p <PID> -o pid,ppid,user,cmd     # ابتدا اطلاعات کامل را ببینید

sudo kill -15 <PID>                  # روش نرم
sudo kill -9  <PID>                  # اگر بسته نشد، روش اجباری
```

پس از kill، دوباره اسکریپت را اجرا کنید تا مطمئن شوید پردازش دوباره راه‌اندازی نمی‌شود (بخش‌های کرون‌جاب و سرویس‌ها را هم چک کنید).

---

## ۲. چگونه یک کرون‌جاب مشکوک را حذف کنیم

```bash
crontab -e                # کرون‌جاب کاربر فعلی - خط مشکوک را حذف یا با # غیرفعال کنید
sudo crontab -e           # کرون‌جاب روت

ls -la /etc/cron.d/ /etc/cron.daily/ /etc/cron.hourly/
sudo rm /etc/cron.d/<نام فایل مشکوک>
```

---

## ۳. چگونه فایل‌های مشکوک را پاک کنیم

```bash
cat /مسیر/فایل/مشکوک              # قبل از حذف، محتوا را ببینید (اگر متنی است)
sha256sum /مسیر/فایل/مشکوک        # هش را روی VirusTotal.com چک کنید
rm -f /مسیر/فایل/مشکوک            # فقط پس از اطمینان کامل حذف کنید
```

اگر فایل در حال اجراست، اول پردازش مرتبط را طبق بخش ۱ ببندید.

---

## ۴. چگونه اتصالات شبکه مشکوک را قطع کنیم

```bash
sudo ss -tulpn | grep <PORT>          # پیدا کردن پردازش مرتبط با پورت
sudo kill -9 <PID>                    # بستن پردازش

sudo ufw deny from <IP_مشکوک>         # مسدود کردن IP با فایروال
# یا
sudo iptables -A INPUT -s <IP_مشکوک> -j DROP
```

---

## ۵. چگونه کلید SSH غیرمجاز را حذف کنیم

```bash
nano ~/.ssh/authorized_keys
# خط کلید غیرمجاز را حذف کرده و ذخیره کنید
```

توصیه می‌شود پس از هر مورد مشکوک، کلیدهای SSH را از نو بسازید و رمزهای عبور مرتبط را عوض کنید:
```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

---

## ۶. در صورت نیاز به ریست کامل سیستم

اگر مورد پیدا شده جدی است (روت‌کیت یا بدافزار عمیق) و مطمئن نیستید سیستم کاملاً پاک شده:

1. از داده‌های مهم خود (نه فایل‌های اجرایی مشکوک) بک‌آپ بگیرید.
2. سیستم‌عامل را از یک نسخه‌ی رسمی و تازه نصب کنید.
3. رمزهای عبور همه سرویس‌ها (ایمیل، بانک، شبکه‌های اجتماعی) را از یک دستگاه امن دیگر تغییر دهید.
4. احراز هویت دو مرحله‌ای (2FA) را روی حساب‌های مهم فعال کنید.

---

## نکته درباره‌ی هشدارهای اشتباه (False Positive)

جستجوی کلمه‌ی `miner` می‌تواند به‌اشتباه روی پکیج‌های قانونی که این کلمه در نامشان هست (مثل کتابخانه‌ی پایتون `pdfminer`) هم فعال شود. اگر موردی پرچم خورد، حتماً **مسیر کامل فایل** را بخوانید — اگر داخل `site-packages`، `dist-packages` یا مسیرهای شناخته‌شده‌ی کتابخانه‌هاست، معمولاً بی‌خطر است؛ نگرانی واقعی زمانی است که فایل در `/tmp`، `/dev/shm`، یا مسیرهای پنهان/تصادفی باشد.

---

## نکات پیشگیرانه برای آینده

- فقط از منابع رسمی نرم‌افزار نصب کنید.
- روی لینک‌های ناشناس یا مشکوک (به‌خصوص در پیام‌های کاری/فریلنسری) کلیک نکنید.
- به‌روزرسانی امنیتی را مرتب نصب کنید: `sudo apt update && sudo apt upgrade`
- اسکریپت را به‌صورت هفتگی اجرا کنید تا زودهنگام مشکلات را تشخیص دهید.
- در اندروید/Termux فقط از Google Play یا F-Droid نصب کنید.
- فایل‌های گزارش (`security_report_*.txt`) حاوی اطلاعات حساس (لیست پردازش‌ها، اتصالات شبکه، اثرانگشت کلید SSH) هستند؛ با دسترسی 600 ساخته می‌شوند — آن‌ها را به‌صورت عمومی به اشتراک نگذارید.
